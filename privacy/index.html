Privacy and data

For the Times Table Worksheets, Division Worksheets, and Color by Number pages. The Times Tables Games app has a page of its own.

The short version

  • Nothing you type is collected or sent anywhere. The worksheets are made in your browser.
  • There are no accounts, sign-ins, cookies, ads, analytics, or tracking.
  • Your settings are saved only in your own browser, so the page remembers them next time. Clearing your browser's data for this site erases them.
  • The tool never asks for names or other personal details. The Name and Date lines are blank, for writing on the printed page.
  • The pages load everything, fonts included, from this site and contact no other site.

The following covers data and privacy in more detail. The code is public, so you can also check it yourself.

What the tool is

  • Static web pages (HTML, CSS, and JavaScript) that build printable worksheets and answer keys in the browser.
  • There is no server-side code, database, or API. Nothing is uploaded, and no account is needed.
  • The source code is public: github.com/amceachin-code/multiplication-worksheet.

Information collected

  • None. The tool doesn't collect personal information from anyone, including students and children under 13.
  • The pages have no forms that submit anywhere. Besides loading their own files from this site, they make no network requests: no tracking pixels, beacons, or background calls.
  • Because nothing is collected, nothing is shared with or sold to anyone.

What is stored on the device

  • Each page saves its settings in the browser's local storage, under times-table-worksheets:v1, division-worksheets:v1, or color-by-number:v1.
  • Saved settings: the numbers chosen, the number range, the grid size, the number of worksheets, the layout, position, and picture choices, the optional worksheet title, and a random number that sets the shuffle order.
  • The Answer key switch is never saved, so each visit starts with it off.
  • Saved settings stay on that device and are never sent anywhere. On a shared computer, the next person to open the page sees the last settings used, including any title typed in. Clearing the browser's site data for www.andrew-mceachin.com removes them.
  • No cookies are set.

Network requests

  • All requests go to www.andrew-mceachin.com over HTTPS: the page itself, the shared stylesheet, the worksheet pages' scripts (two shared by every page, plus the Color by Number page's own logic and one file for each of its pictures), and up to four font files, each fetched when text first needs it.
  • No third-party services are used: no font services, content delivery networks, analytics, or ads. The fonts (Andika and Atkinson Hyperlegible, both under the SIL Open Font License) are served from this site.

Hosting

  • The site is hosted on GitHub Pages, a service of GitHub, Inc.
  • Like any web host, GitHub's servers receive the standard details of each request (such as IP address and browser type) to deliver the pages. GitHub's documentation says it logs visitor IP addresses for security purposes. See the GitHub General Privacy Statement.
  • The site owner gets no visitor logs or analytics.

Web filters and Clever

  • Only www.andrew-mceachin.com needs to be allowed.
  • The tool works as a plain link, for example a custom link or bookmark in the Clever Portal. It needs no single sign-on, rostering, or LTI integration.
  • It works in current web browsers. It has been tested in Chrome on a computer and Safari on iPhone.
  • Printing uses the device's own print dialog. Nothing about printing goes to this site.

Changes and contact

  • Every change to the pages is public in the code's change history. This page will be updated if any of the above changes.
